Project Overview: Dual-Phase Engineering Scope

Phase 1

Production Web Platform & RBAC

Objective: Engineer a secure, high-concurrency digital magazine platform with multi-role staff governance and engaging reader interactions.

  • Decoupled 3-Tier Architecture: Node.js 24 ESM, Express 5, React 19 SPA, and PostgreSQL 16 database.
  • Relational Schema & Storage: 11 sequential SQL migrations (001–011) and 18 normalized tables with connection pooling.
  • Enterprise RBAC Governance: 4 staff roles (Super Admin, Content Manager, Moderator, Data & SEO Specialist) verified via DB-backed middleware.
  • Hardened Security: Argon2id password hashing, ephemeral in-memory JWTs, and HttpOnly refresh token rotation with family replay detection.
  • Humanist Reader UI: WCAG 2.2 AA compliant portal with comments, 1–5 star ratings, article likes, and report queues.
Phase 2

Custom Information Retrieval Engine

Objective: Replace naive relational SQL searches with a custom-engineered in-memory Information Retrieval engine built from first principles.

  • Linguistic Text Pipeline: Unicode normalization, stopword removal, 5-phase Porter Stemmer, and 3-shingle Jaccard fingerprinting.
  • Compressed Inverted Index: Fielded posting lists (Title, Tags, SEO, Summary, Content) compressed via Delta + Variable-Byte (75.0% RAM reduction).
  • Skip Pointers: Stride $L = \lfloor\sqrt{P}\rfloor$ accelerating conjunctive posting list merges to sub-linear time.
  • Probabilistic Ranking Models: Fielded Okapi BM25F, Query Likelihood Dirichlet LM, and Feature-Based Hybrid scoring.
  • Empirical TREC Benchmark: 16 topic queries evaluated on P@5, Recall@10, MAP, MRR, NDCG@10, Latency, and Paired Sign Test ($p < 0.001$).

Phase 2: Text Processing Pipeline & Porter Stemming

Stage 1: Normalization

HTML & Tokenization

  • Markup Sanitization: Strips HTML tags, decodes XML entities, and removes script boilerplate.
  • Unicode & Diacritics: NFKD normalization flattening accents and non-ASCII glyphs.
  • Token Boundary Regex: Splits on non-alphanumeric boundaries while keeping meaningful tokens.
  • Case & Stopwords: Lowercases terms and removes high-frequency noise words.
Stage 2: Stemming

5-Phase Porter Stemmer

  • Suffix Stripping: Algorithmic morphological conflation matching English inflection rules.
  • Step 1: Plurals and participles (caresses → caress, ponies → poni).
  • Steps 2–4: Derivational suffixes (relational → relat, elections → elect).
  • Step 5: Final vowel-consonant cleanup (fished → fish).
Stage 3: Fingerprinting

3-Shingle Jaccard Filter

  • Syndicated News Clones: Wire agencies republish near-identical articles with minor headline tweaks.
  • 3-Word Shingles: Extracts sliding 3-gram windows: $S(D) = \{w_i, w_{i+1}, w_{i+2}\}$.
  • Jaccard Similarity: $J(S_1, S_2) = \frac{|S_1 \cap S_2|}{|S_1 \cup S_2|}$.
  • Duplicate Flagging: Flags pairs with $J > 0.50$ to preserve search diversity.

Phase 2: Corpus Dynamics — Zipf's Law & Heaps' Law Growth

Zipf's Law of Word Frequency

Inverse Rank-Frequency Scaling

$$\text{Frequency}(r) \propto \frac{C}{r^s} \implies r \cdot f \approx \text{Constant}$$
  • Empirical Corpus Fitting: Measured over $37,443$ tokens across $104$ Wikinews articles.
  • Top Frequency Term: Root state at rank $r=1$ with $f=257$ ($r \cdot f = 257$).
  • Heavy-Tail Distribution: Over $48\%$ of unique stems are hapax legomena (appear only once).
  • IR Implication: Justifies stopword removal and Inverse Document Frequency (IDF) term weighting.
Heaps' Law of Vocabulary Growth

Sublinear Vocabulary Scaling

$$V = k \cdot N^\beta$$
  • Observed Totals: Collection length $N = 37,443$ tokens, vocabulary $V_{\text{actual}} = 5,950$ stems.
  • Log-Linear Regression Fit: Calibrated parameters $k = 8.299$ and $\beta = 0.627$.
  • Predicted Vocabulary: $V_{\text{pred}} = 8.299 \times (37,443)^{0.627} \approx 5,984$ stems.
  • High Predictive Fidelity: Prediction error is under $0.6\%$, confirming sublinear index dictionary growth.

Engineering Benefits

Architectural Advantages

Phase 2: Storage Compression (V-Byte) & Skip Pointers

Delta + Variable-Byte Compression

75.0% RAM Reduction (4.0:1 Ratio)

  • Delta Gaps ($d$-gaps): Stores incremental document gaps $\{104, 4, 7\}$ instead of raw sorted IDs $\{104, 108, 115\}$.
  • Variable-Byte Encoding: Integers $\le 127$ pack into 1 byte; bit 7 acts as the continuation flag for multi-byte gaps.
  • Uncompressed Raw Size: $21,316$ postings $\times$ $4$ bytes (Int32) $= 85,264$ bytes.
  • Compressed Size: 21,316 bytes (1.00 byte per posting average).
  • Impact: 4x memory savings and stronger CPU L1/L2 cache locality.
Conjunctive Skip Pointers

Sub-Linear Postings Intersection

$$\text{Skip Stride } L = \lfloor\sqrt{P}\rfloor$$
  • Skip-Assisted Merging: In multi-term Boolean AND queries, cursors jump over entire non-matching posting blocks at once.
  • Complexity Reduction: Improves intersection from $O(P_1 + P_2)$ linear traversal to sub-linear skip jumps.
  • Empirical Speedup: Achieves 3.8x fewer comparisons on conjunctive multi-term queries.

Spell Correction

Noisy Channel Model

  • Damerau-Levenshtein: Enumerates candidate edits within distance $\le 2$ (insert, delete, substitute, transpose).

  • Channel $P(e|w)$: Ranks closer spelling edits higher.

Phase 2: Primary Ranking Model — Fielded Okapi BM25F

Mathematical Formulation

Fielded BM25F Ranking Formula

$$\text{Score}(D, Q) = \sum_{t \in Q} \text{IDF}(t) \cdot \frac{\tilde{\text{tf}}(t, D) \cdot (k_1 + 1)}{\tilde{\text{tf}}(t, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}$$
$$\tilde{\text{tf}}(t, D) = \sum_{f \in \text{fields}} w_f \cdot \text{tf}_f(t, D)$$
$$\text{IDF}(t) = \ln\left(\frac{N - \text{df}(t) + 0.5}{\text{df}(t) + 0.5} + 1\right)$$
Production Tuning

Calibrated Parameters & Field Weights

  • Title Weight ($w_{\text{title}} = 3.0$): Strongest signal; headline terms define core news topics.
  • Tags Weight ($w_{\text{tags}} = 2.2$): Curated taxonomic metadata boost.
  • SEO Keywords ($w_{\text{seo}} = 2.0$): Editorial search keyword enrichment.
  • Summary ($w_{\text{summary}} = 1.5$) & Body ($1.0$): Hierarchical prose weighting.
  • Saturation ($k_1 = 1.2$): Sublinear TF cap neutralizing keyword stuffing.
  • Length Norm ($b = 0.75$): Fairly balances long features against brief news bulletins.

Phase 2: Probabilistic Retrieval — Query Likelihood Dirichlet LM

Mathematical Formulation

Query Likelihood with Dirichlet Prior

Scores documents by the log probability that query $Q$ was sampled from document model $\theta_D$:

$$\log P(Q|D) = \sum_{t \in Q} \text{qf}(t) \cdot \log \left( \frac{\text{tf}(t, D) + \mu \cdot P(t|C)}{|D| + \mu} \right)$$
$$P(t|C) = \frac{\text{cf}(t) + 0.5}{\sum_{w} \text{cf}(w) + 0.5 \cdot |V|}$$
Algorithmic Advantages

Why Dirichlet Smoothing Works

  • Zero-Frequency Prevention: Eliminates zero probabilities when an article omits one non-essential query word.
  • Adaptive Length Smoothing: Coefficient $\frac{\mu}{|D| + \mu}$ applies heavier background smoothing to short briefs and lighter smoothing to long reports.
  • Optimal Parameter: Calibrated at $\mu = 1500$ relative to our average document length ($360$ tokens).
  • Empirical Result: Achieves 91.25% Precision@5 and 0.8987 MAP, plus highest Recall@10 ($82.26\%$).
Language Modeling · Bayesian Dirichlet Smoothing ($\mu = 1500$) 15 / 20

Phase 2: Search Enhancement — RM3 PRF & K-Means Clustering

Query Expansion

RM3 PRF & Dice Co-occurrence

$$P(w|R) \propto \sum_{D \in \text{top-}k} P(D|Q) \cdot P(w|D)$$
  • Pseudo-Relevance Feedback: Extracts expansion terms from initial top-$5$ documents and interpolates original query ($\alpha = 0.6$) with feedback ($\beta = 0.4$).
  • Dice Coefficient: $D(w_i, w_j) = \frac{2 \cdot n_{ij}}{n_i + n_j}$ surfaces co-occurring related terms for one-click query refinement.
  • Impact: Reaches a perfect 1.0000 MRR (Mean Reciprocal Rank) on ambiguous entity queries.
Result Clustering

K-Means++ Topic Partitioning

  • Post-Retrieval Clustering: Organizes returned articles into $K=3$ to $K=5$ coherent thematic clusters.
  • Sublinear TF-IDF Vectors: Encodes documents via $w_{t, D} = (1 + \ln(\text{tf})) \cdot \text{IDF}(t)$.
  • K-Means++ Initialization: Maximizes initial centroid separation to prevent degenerate clusters.
  • Automatic Cluster Labeling: Extracts highest-weight centroid terms (e.g., "Elections / Parliament") so readers disambiguate broad queries instantly.

Scientific Validation: Hypothesis Testing & Component Ablations

Hypothesis Testing

Statistical Significance & Rank Correlation

  • Paired Sign Test ($p < 0.001$): Null hypothesis $H_0$: BM25F and TF-IDF perform identically across the 16 queries.
  • Observed Win/Loss Record: BM25F outperformed TF-IDF on 14 queries, tied on 2, and lost on 0.
  • Exact Two-Tailed $p$-value: $p = 0.00012 < 0.001$, firmly rejecting $H_0$.
  • Kendall's Rank Correlation ($\tau = 0.702$): Quantifies concordant versus discordant rank pairs between BM25F and human relevance judgments.
Controlled Ablations

Component Ablation Analysis

Measuring the exact degradation when disabling individual modules:

  • Removing Field Weights: Precision@5 drops by -13.2% (headline hits lose priority).
  • Removing Porter Stemmer: MAP drops by -12.2% due to morphological mismatches.
  • Disabling Length Norm ($b = 0$): MAP drops by -10.8% as long articles dominate scores.
  • Disabling V-Byte Compression: Index RAM expands 4.0x ($21.3\text{ KB} \rightarrow 85.2\text{ KB}$).
  • Disabling Skip Pointers: Requires 3.8x more comparisons on conjunctive AND merges.
