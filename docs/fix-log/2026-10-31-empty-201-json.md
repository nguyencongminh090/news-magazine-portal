# 2026-10-31 23:20 — #18 report submit showed "Unexpected end of JSON input" although saved
## Prompt
Real-browser pass of ArticlePage (#18): sending a report showed a JSON parse error; DB row existed.
## Root cause
`POST /articles/:slug/reports` and `/comments/:id/reports` answer `201` with an empty body (design). `authClient.request` only treated `204` as body-less and called `res.json()` on the 201, which throws. jsdom tests mock `request`, so they never saw a real Response.
## Fix
`frontend/src/auth/authClient.js` `request`: read `res.text()`, return `null` when empty, else `JSON.parse`. Scope: only that line.
## Verification
New test `authClient.test.js` "a 201 with an empty body ... resolves to null" failed first (SyntaxError), passes now; full frontend suite 83/83. Real browser: comment + article report show "Reported. Thank you." on first submit.
